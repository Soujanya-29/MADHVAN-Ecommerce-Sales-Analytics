# # MADHVAN E-Commerce Sales Analytics

## Project Overview
This project analyzes e-commerce sales data using Power BI and Python to understand sales, profit, customer behavior, and business performance.

## Tools Used
- Power BI
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
- Orders.csv
- Details.csv

## Project Files
- ecommerce_sales_analysis.py – Python analysis code
- requirements.txt – Required Python libraries
- Project_Report.pdf – Project report
- Orders.csv – Orders dataset
- Details.csv – Sales details dataset

## Objective
To analyze sales data and identify useful business insights that can support better decision-making.
